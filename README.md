# Nalwoga Tracy — Software Engineer Portfolio 🚀🇺🇬

A modern, responsive, developer-style portfolio website built for **Nalwoga Tracy**, a 23-year-old Software Engineer studying at **Bugema University, Uganda**.

Built using **React 19 + Vite + Tailwind CSS v4 + Lucide Icons**.

---

## ✨ Features

- **📱 Fully Responsive Design**: Built mobile-first for all device screen sizes.
- **🌙 Dark & Light Theme**: Toggle between sleek dark developer mode and clean light mode (persisted in local storage).
- **🚀 Featured Projects**: Showcases 5 core software engineering projects:
  1. **Bugema Academic Connect** (Academic Management & Collaboration System)
  2. **InvoiceHub** (Automated Billing & Invoice Generation Platform)
  3. **IT Market** (E-Commerce Platform for Hardware & Services)
  4. **Smart Farmer** (AgriTech Advisory & Produce Market Price Platform)
  5. **Christ Formed Church Website** (Media & Sermon Community Portal)
- **🛠️ Interactive Skills Showcase**: Filterable and searchable skill matrix covering Backend (Spring Boot, Java, REST APIs), Frontend (React, JavaScript, TypeScript, Tailwind), Database (PostgreSQL, MySQL), and Engineering Practices.
- **🎓 Education & Certifications**: Detailed academic profile for Bugema University.
- **📄 Downloadable & Printable CV**: Interactive in-app CV viewer with one-click HTML/PDF resume generation.
- **📧 Contact Form**: Direct email, WhatsApp link, location details, and interactive message form.

---

## 🛠️ Getting Started

### 1. Run locally in development mode:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for production:
```bash
npm run build
```
The output files will be generated in the `dist/` directory ready for deployment.

---

## 🌐 How to Deploy on Vercel

1. Push this repository to **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit for Nalwoga Tracy"
   git remote add origin https://github.com/nalwogatracy/tracy-portifolio.git
   git push -u origin main
   ```

2. Go to [Vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New Project"** and select your `tracy-portifolio` repository.
4. Click **"Deploy"** — Vercel will automatically build and host your site with free SSL & custom domain support!
